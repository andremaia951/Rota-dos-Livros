Rota dos Livros

O Rota dos Livros é um projeto pessoal criado para apresentar livros e incentivar a descoberta de novas leituras.

Este repositório reúne a versão inicial do site, desenvolvido como um projeto de aprendizado com tecnologias da web. A ideia é recuperar o trabalho original e evoluí-lo gradualmente, preservando sua proposta e modernizando sua estrutura e aparência.

## Estrutura do projeto

- `index.html` — página inicial.
- `pagina1.html`, `pagina2.html` e `pagina3.html` — páginas de conteúdo.
- `contatos.html` — página de contato.
- `css/` — arquivos de estilo.
- `Imagens/` — imagens utilizadas pelo site.

 Tecnologias

- HTML
- CSS

Objetivo

Transformar o Rota dos Livros em um projeto cada vez mais organizado, agradável de usar e acessível, enquanto serve como espaço de aprendizado e prática no desenvolvimento web.

Status

Projeto em recuperação e modernização. Novas melhorias serão adicionadas ao longo do desenvolvimento.
