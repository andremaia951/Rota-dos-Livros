# Rota dos Livros

O Rota dos Livros é um projeto pessoal criado para apresentar livros e incentivar a descoberta de novas leituras.

Este repositório também reúne outros projetos pessoais de desenvolvimento web, feitos para praticar e evoluir conhecimentos em programação.

## Projetos

### Rota dos Livros
Site pessoal de descoberta e apresentação de livros.

- Arquivo principal: `index.html`
- Páginas adicionais: `pagina1.html`, `pagina2.html`, `pagina3.html` e `contatos.html`
- Estilos: pasta `css/`
- Imagens: pasta `Imagens/`

### Notefy
Aplicação simples para criar notas com título, conteúdo e tag.

- [Abrir os arquivos do Notefy](Notefy/)
- HTML, CSS e JavaScript
- Permite adicionar e excluir notas
- As notas ainda não ficam salvas depois que a página é recarregada.

## Tecnologias

- HTML
- CSS
- JavaScript

## Objetivo

Manter neste repositório projetos pessoais de aprendizado, recuperar trabalhos antigos e desenvolver novas ideias aos poucos.

## Status

Projetos em desenvolvimento e atualização gradual.
